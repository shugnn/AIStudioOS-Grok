# AIStudioOS-Grok 产品介绍（纠偏后）

**以 [`PRODUCT_CONSTITUTION.md`](PRODUCT_CONSTITUTION.md) 为准。**

## 一句话

**模型无关的 AI 工作室操作系统骨架**：人类授权与直操；控制平面强制预算/权限/验收；LLM 与其它 AI 只是可插拔的中枢或工人，不是产品本体。

## 不是什么

- 不是 Grok 聊天窗口的别名  
- 不是「轨道员代写脚本 = 自治完成」  
- 不是已验收的生产 7×24  
- 不是自动交易系统  

## 是什么

| 层 | 内容 |
|----|------|
| 控制平面 | 目标/任务状态机、硬预算、硬权限、检查点 |
| 执行层 L1 | 本机锁、唤醒、急停 |
| 角色后端 | script / llm / null … **可替换** |
| 监督与证据 | 有效产出计量、监督策略、Issue 留痕 |
| 业务实验 | 如 Exp-05；脚手架 ≠ 自治 PASS |

## 人类如何用（完工态）

1. 安装与配置（见 USER_GUIDE）  
2. 声明目标与授权（含是否开网、预算）  
3. 启动 Runner / 有界任务  
4. 查看状态与产物；需要时急停  
5. **不**要求某一聊天 AI 在线才能运转  

## 当前诚实进度

- 控制平面 + L1 + 监督/浸泡证据：有  
- 可插拔 LLM 中枢驱动「自己写业务代码」：**未完成（纠偏主攻）**  
- Exp-05 手写采集脚本：仅 baseline
