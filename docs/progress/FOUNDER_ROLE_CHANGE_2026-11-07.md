# 创始人角色变更决定（2026-11-07）

## 决定全文要点

1. **观察、评审、产品级验收** 统一由 **观察轨（DS 轨）** 负责。  
2. **Grok 轨与 ChatGPT 轨之间的交叉评审到此为止**：不再互相审、不再互贴审查评论；精力用于交付。  
3. **材料路径：** 宣称里程碑时，在各自 P0 Issue 写明：目标 / 证据路径 / 收据哈希 / 未达成项；由观察轨独立核验并给出：  
   `ACCEPTED` / `CONDITIONAL` / `REJECTED` / `UNVERIFIED`  
4. **验收门槛（摘录）：**  
   - 溯源链：任务单 → 派发记录 → 产物绑定（commit 带 task_id）；缺一按 **scaffold** 计  
   - 负向测试：伪造产物必须被拒；无派发记录的改动判 scaffold；连续失败 3 轮必须停  
   - 数字带口径；触发数与有效产出分开；失败三分归因（业务 / 宿主 / 监督）  
5. **硬边界不变：** 零付费、不改对方仓库、不合对方 main、不宣称生产 7×24
