# Exp-05：多角色美股研究实验室（免费数据 · 非实盘）

**目的：** 用接近真实业务的复杂链路，压测控制平面 + 多角色分工，而不是单兵小脚本。

**非目标：** 自动实盘下单、付费数据源、生产 7×24 宣称。

## 业务目标（一句话）

在**零新增付费**前提下，从**免费**公开来源动态（或半动态）收集美股相关数据 → 整理 → 分析 → 产出**短线/中线观察池**与**策略草案**，并由独立角色验收；全程受预算与权限门约束。

## 多角色（必须分人，禁止一人包办验收）

| 角色 | 职责 | 不可做 |
|------|------|--------|
| **研究经理 Manager** | 拆目标、提任务、排优先级 | 不自行 Accept |
| **数据侦察 DataScout** | 选定免费源、记录许可与限速 | 不写策略结论 |
| **采集 IngestWorker** | 拉取/更新本地数据湖 | 不改策略文件 |
| **整理 Curator** | 清洗、对齐字段、去重、质量报告 | 不挑股票池 |
| **分析 Analyst** | 因子/波动/流动性等特征 | 不最终拍板池子 |
| **池与策略 PoolStrategist** | 短线池、中线池、规则草案 | 不绕过 Verifier |
| **独立验收 Verifier** | 对照验收清单拒收/通过 | 不参与采集与写策略 |
| **人类创始人** | 开网权限、是否允许半自动采集、是否看池子 | — |

## 免费数据源（候选 · 实施前再钉死 1～2 个）

| 来源 | 用途 | 注意 |
|------|------|------|
| Yahoo Finance（如 `yfinance`） | 日/周行情 | 需 **network** 权限；非官方 SLA |
| Stooq | CSV 行情 | 需网络或人工下载 |
| SEC EDGAR | 公司披露 | 免费；解析重 |
| 创始人投放的本地文件 | 离线回归 | **默认先走这条**做通链路 |

**禁止：** 付费终端、未批准的付费 API、自动券商下单。

## 阶段与产物（工程性能看点）

| 阶段 | 产物目录 | 验收要点 |
|------|----------|----------|
| S0 权限与预算声明 | `docs/progress/exp05/` | 预算 $0 付费；network 默认关 |
| S1 数据源卡片 | `sources/*.md` | 许可、字段、更新频率 |
| S2 原始落地 | `datalake/raw/` | 可复现拉取命令或文件哈希 |
| S3 清洗表 | `datalake/clean/` | 行数、缺失率、主键 |
| S4 特征 | `features/` | 至少 3 类特征有定义 |
| S5 短线观察池 | `pools/shortlist_short.json` | 入选规则可执行、可复算 |
| S6 中线观察池 | `pools/shortlist_medium.json` | 同上 |
| S7 策略草案 | `strategies/draft_*.md` | 仅研究草案，含风险声明 |
| S8 独立验收 | `verify/report.json` | Verifier ≠ Strategist |

## 控制平面映射

- Goal：`Exp-05 US Equity Lab`
- 每个阶段至少 1 个 Task：PROPOSED → APPROVED → RUNNING → VERIFYING → ACCEPTED/REJECTED
- Manager 只 propose；Accept 仅 Verifier 路径
- `git_push` / 实盘 API：保持默认拒绝
- `network`：**未书面批准前禁止**；先用 `fixtures/` 跑通 S3–S8

## 成功标准（实验级，非投资建议）

1. 至少 **5 个角色**在审计日志中留下可区分动作（可用独立脚本模拟角色边界）。
2. 产出短线池、中线池各 ≥1 份，规则可复算。
3. Verifier 至少做过 **1 次拒绝再修订**（证明非自嗨通过）。
4. 全程 **$0 付费**；无自动下单代码路径。
5. 证据进 `experiments/exp05-us-equity-lab/results/` + Issue #9。

## 明确失败标准

- 只有单一脚本从头到尾写结论且无独立验收
- 使用付费源或密钥
- 出现下单/券商 API
- 无法复算池子规则

## 实施顺序（建议）

1. **离线夹具通路**（本目录 `fixtures/`）→ 证明多角色状态机  
2. 创始人若批准 **仅免费源的 network** → 再开受限采集  
3. 人工审阅池子与策略草案（研究用途）

## 法律与风险

产出为**研究与工程压测**，不是投资建议；不保证收益；不授权实盘。
